# מצב בדיקת קוד אוטומטית

`luau-check.sh` הוא קובץ שהועתק ממערכת אחרת. הוא נועד לסדר קוד באמצעות StyLua ולבדוק שגיאות באמצעות Selene.

- הקובץ נשמר כאן, אך אינו מחובר להפעלה אוטומטית ב־Codex או ב־Git.
- הוא מצפה לקלט בפורמט של Claude ולמשתנה `CLAUDE_PROJECT_DIR`, ולכן העברת התיקייה לבדה אינה מספיקה להפעלתו ב־Codex.
- בבדיקה מקומית נמצאו `jq`, `stylua` ו־`selene`. הם לא הופעלו.
- הקובץ משנה את עיצוב הקוד. לפני שימוש עתידי צריך להתאים את הקלט והנתיבים, לבחור את הקבצים שייבדקו ולבדוק את ההתנהגות בקבצים זמניים.
- כרגע מסדרים את הפרויקט בלבד. אין להפעיל את הקובץ או לבצע פעולות ב־Studio במסגרת הסידור.
