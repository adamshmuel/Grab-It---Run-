# בדיקות אינטגרציה מקומיות של V1

כלי בדיקה בלבד. המקורות נמצאים כאן; Rojo מציב את התבניות בתוך ServerStorage.GrabItQA, שם הן אינן מופעלות. אין לערוך את המקור דרך Studio.

## הפעלה בטוחה

מפעילים רק מתוך Edit בקובץ הפרויקט המאומת, דרך Studio MCP. יוצרים עותק זמני של מודול launch, טוענים אותו ומפעילים את הפונקציה שהוא מחזיר. הפרמטרים הם מספר שחקנים, משך מרבי, והאם לעצור אחרי בדיקת האיסוף. פרמטר רביעי, LoopSmoke, בודק יציאות חוזרות במצב דליל בלי להמתין לסגירת הסיבוב; מתחילים בו מאיסוף פריט אחד בלבד. הגבולות הם 1–8 שחקנים ועד 900 שניות. קוראים את התוצאה מתוך המאפיין GrabItQAResult של הפרויקט.

הכלי מציב זמנית את שני runners במקומות המתאימים, מפעיל ExecuteMultiplayerTestAsync ומסיר אותם בסיום. מופעי Studio הנוספים שייכים לשרת ולשחקני הבדיקה. EndTest סוגר אותם ומשאיר את עורך הפרויקט פתוח. יש timeout שמגביל את הבדיקה. אין לשמור את המשחק בזמן שתסריטי הבדיקה הזמניים מחוברים.

הגרסה המותקנת של JestRobloxRunner, מספר 0.4.6, בודקת כל קריאה למערכת הבדיקות. המקור שמצורף ל־CLI שלה מתעד ויתור על הרצה כשכבר קיים המאפיין JestRobloxRunClaimed. הכלי משתמש בתיאום הזה רק לזמן הבדיקה ומשחזר את הערך הקודם. הוא אינו משנה או מכבה את ה־plugin, אינו מפעיל LoadString, אינו משנה הרשאות API ואינו כותב ל־DataStore.

## מה נבדק

כל שחקן מתחיל בלי התקדמות, ממתין לטעינת הדמות והולך במפה באמצעות Humanoid:MoveTo. בקשות האיסוף נשלחות דרך RemoteEvent הרגיל של המשחק. נבדקים חפצים אישיים, חמישה פריטים, האטה, ניסיון חוזר, הפקדה, יציאה נוספת, אובדן מטען בסגירה, שמירת המטבעות שכבר הופקדו, פתיחה מחדש והמשך משחק. בסיום בדיקה מלאה שחקן בדיקה אחד יוצא; האחרים מאשרים שהיתרה בממשק לא התאפסה.

זו אינה בדיקת מחוות touch או קלט מקלדת. אלה נבדקים בנפרד. ערוץ QA קיים רק בזמן הבדיקה ואינו מעניק מטבעות. ההמתנה למצב שרת עדכני נחוצה גם בכלי עצמו: הגעה למיקום אינה אומרת שהבחירה החדשה כבר הגיעה דרך הרשת.

## מדידת ביצועים

בהרצה של לפחות 600 שניות המדידה מתחילה רק כאשר המאפיין MeasureFrames בערוץ QA של שרת הבדיקה מקבל true. לפני כן מגדירים ומאמתים רזולוציה בפועל. מעבר מ־false אל true מאפס את המדדים. כל שחקן אוסף 600 שניות של RenderStepped, מספר frames ומספר frames שאורכם מעל 1/30 שנייה. בנוסף נמדדות דגימות באורך שנייה לפחות, מינימום FPS ומספר דגימות מתחת ל־30 FPS; אחר כך הוא מסיים את היציאה הנוכחית. הבדיקה מוגבלת בזמן גם אם המדידה לא הופעלה.

מתעדים רזולוציה, איכות גרפיקה בפועל, חומרת המחשב, גרסת Studio, מספר שחקנים והפרעות מדידה כמו צילום או debugging. תוצאה מהירה במצב Automatic אינה אישור לדרגת גרפיקה 5. הדמיית נייד על Mac אינה בדיקת חומרה של טלפון.
