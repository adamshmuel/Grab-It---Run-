# Grab It & Run!

פרויקט Roblox מקומי. מקור הקוד נמצא בתוך src; מסמכי ההגדרות בתוך docs/specs, ותוכניות המימוש בתוך docs/plans.

## מצב המשחק

נוצרה גרסה מקומית של V1. ההשוואה החזותית העצמאית, בדיקות המודולים, multiplayer ויעד הביצועים עברו בהיקף המתועד. היא עדיין אינה עומדת בכל קריטריוני הקבלה. [מפת הקבלה הקצרה](docs/research/v1-acceptance-status.md) ו[דוח הבדיקות](docs/research/v1-validation.md) מפרטים מה הוכח ומה חסר.

## איזה קובץ פותחים

קובץ העבודה היחיד של המשחק:

`build/GrabItV1_DesktopMobile.rbxlx`

לבקשת אדם בתאריך 24/10/2026, השמירה המקומית של קובץ העבודה הזה נכללת כעת בתוך Git. שומרים באותו קובץ; אין צורך ליצור סביבה נוספת לכל בדיקה. קוד מסונכרן עדיין משתנה במקורות המקומיים דרך Rojo.

מקורות דגמי החפצים נמצאים בתוך assets/collectibles. תוצרי הדגמים נשמרים בנפרד בתוך build/prototypes; אין צורך לפתוח אותם כסביבות משחק נוספות.

בתאריך 23/10/2026 הוסרו 18 סביבות בדיקה שסיימו את תפקידן ו־13 הפניות ישנות שלהן מרשימת הקבצים האחרונים. קובץ העבודה הפתוח והשמירה הידנית של אדם בשורש הפרויקט נשמרו ללא שינוי. השמירה הידנית היא גיבוי, ולא קובץ עבודה שני. קוד המקור והראיות נשמרו. כללי הניקוי נמצאים בתוך rules/studio.md.

## עבודה מקומית

עובדים במופע Studio אחד של קובץ המשחק הייעודי. משתמשים ב־default.project.json עבור Rojo, ומוודאים שהחלון הוא של הפרויקט הזה לפני סנכרון. אין לערוך קוד מסונכרן ישירות בתוך Studio.

הפקודה הבאה מיועדת להרצה משורש הפרויקט, כדי לסנכרן אל קובץ העבודה שכבר פתוח. יתר תוצרי build נשארים מחוץ ל־Git. בנייה מחדש של קובץ העבודה עלולה להחליף תוכן שנשמר ידנית בתוך Studio; אין צורך בכך לעדכון קוד רגיל.

```sh
rojo serve default.project.json --port 34872
```

את ה־tests מריצים דרך MCP במצב Edit של אותו פרויקט, מתוך ServerStorage.GrabItTests. tools/tests/run.luau הוא מקור ה־runner. אין צורך לפתוח מופע Studio חדש בכל סבב. test.project.json משמש לבנייה מבודדת כאשר נדרשת בדיקה כזאת, ולא כזרימת עבודה רגילה.

## שמירה ופרסום

אדם שמר את המשחק לענן ואישר גישת API מתוך Studio במשחק הזה בלבד. הגישה הופעלה ונבדקה שמירה אמיתית בשני שרתי Solo עוקבים: 0, הפקדה ל־30, כניסה מחדש עם Copper וללא מטען, והפקדה נוספת ל־31. הבדיקה השתמשה ב־DataStore נפרד; נתוני הבדיקה והסימון הזמני הוסרו. Studio רגיל עדיין שומר רק בזיכרון ומציג זאת. המשחק נשאר פרטי ולא פורסמה גרסה נוספת. [מצב הקבלה](docs/research/v1-acceptance-status.md) מפרט ראיות ומגבלות. רק אדם מבצע push.
