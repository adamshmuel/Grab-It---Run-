# מטרות הפרויקט

**מצב: מוסכם עם אדם ומתועד בתאריך 22/10/2026.**

מסמך זה מגדיר מה אנחנו רוצים ליצור ולמה. הוא אינו רשימת features, יעדים מספריים או implementation plan.

## מטרה 1: משחק פשוט, מהיר וממכר

ליצור משחק Roblox בסגנון hyper casual: קל להבנה, מהיר להיכנס אליו, ומעורר רצון להמשיך לעוד סיבוב.

הפשטות צריכה להיות בחוויה של השחקן, בלי לוותר על איכות הביצוע.

## מטרה 2: איכות שמתאימה למשחקים דומים בפלטפורמה

לעמוד ברמת הביצוע שהשחקנים מצפים לה ממשחקים דומים בפלטפורמת Roblox. החוויה צריכה להיות ברורה, מגיבה, יציבה ומלוטשת.

המשחקים להשוואה מוגדרים ב[מפת הרפרנסים](../research/visual-benchmark.md); הקריטריונים לשיפורים מפורטים ב[קבלת השיפורים](v1/improvement-acceptance.md). מסמך זה אינו טוען שכבר בדקנו או השגנו את הרמה הזאת.

## מטרה 3: סיבה לחזור לאורך זמן

ליצור חוויה שכיף לחזור אליה, מעבר להתלהבות מהסיבוב הראשון. ההתקדמות והגיוון צריכים לתמוך ברצון הזה בלי להפוך את המשחק למסובך.

מנגנוני ההתקדמות והתוכן מפורטים בחבילת [שיפורי V1](v1/improvements.md) המוגשת לאדם.

## מטרה 4: מוצר שאפשר לתחזק ולהפיק ממנו הכנסה

לפתח משחק בהיקף שנוכל להשלים ולתחזק, עם אפשרות למודל הכנסות שאינו פוגע בהנאה הבסיסית.

זו שאיפה עסקית, לא הבטחת רווח. מוצרים בתשלום ויעד הכנסה מחוץ ל־V1. האחריות, הפעולה ותנאי הסיום להגדרתם מופיעים ב[עבודה המאוחרת](index.md). מחירי עיצובים במטבעות המשחק אינם מחירים בכסף אמיתי.

## מטרה 5: להשאיר אפשרות למשחקים נוספים מאותו הסוג

ההגדרות והפיתוח יהיו ממוקדים במשחק הראשון. במקביל, נשמר ידע ורכיבים שמתאימים לשימוש חוזר במשחקים עתידיים מאותו הסוג.

ניצור רכיבים משותפים מתוך צרכים אמיתיים של המשחק הראשון. לא נבנה מראש תשתית כללית לסדרת משחקים לפני שנדע מה באמת משותף להם.

## הקשר למסמכי המשחק

[מסמך המשחק המקורי](v1/gameplay.md) מתעד את אישור הבסיס; [מפת V1](v1/index.md) מקשרת להגדרות השיפורים ולמעמדן. מטרות הפרויקט אינן משנות את הכללים המאושרים בו ואינן מכניסות features נוספים לגרסה הראשונה.

תנאי הבדיקה ל־V1 מפורטים במסמכי הקבלה; מדדי חזרה והכנסה ארוכי טווח נשארים עבודה נפרדת עם אחריות ותנאי סיום ב[מפת ההגדרות](index.md). תיעוד המטרות אינו אישור לכתוב קוד או להתחיל עבודה שלא התבקשה.
