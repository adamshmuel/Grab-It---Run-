מסמכי spec מתארים מה השחקן רואה ועושה ולמה. implementation plan נכתב רק לאחר אישור המסמך המתאים; קוד דורש בקשה מפורשת נוספת.

## מטרות וגרסה ראשונה

- [מטרות הפרויקט](project-goals.md) — הכיוון שהוסכם בתאריך 22/10/2026.
- [V1 — הגדרות המשחק](v1/index.md) — המסמך המקשר, גבולות הגרסה וטיוטות נפרדות לכל נושא. gameplay אושר בתאריך 21/10/2026; יתר המסמכים ממתינים לאישור.

## מסמכים להמשך מחוץ לגרסה המוצעת

הרשימה היא תיעוד של נושאים בלבד. היא אינה התחייבות לבנות אותם או אישור לכתוב עבורם תוכנית.

| מסמך עתידי | מה יוגדר בנפרד |
| --- | --- |
| Gamepad ו־VR | קלט ותצוגה למכשירים נוספים |
| הרחבת ההתקדמות | שדרוגים, תוכן ארוך יותר ופתיחת אזורים |
| Social features | פעולות משותפות מעבר לשהות באותו מחסן |
| Cosmetics and monetization | בחירת מראה, חנות ומוצרים בתשלום |
| הרחבת המחסן | מפות, מכשולים ותוכן חדש |
| השקה לציבור | קהל, מכשירים, דרישות פרסום וקריטריוני השקה עדכניים |
| מדידת חזרה והכנסות | יעדים, תקופת מדידה ונתונים שיאפשרו לבחון את מטרות המוצר |

נושאי מפה, Controls, התקדמות ושמירה כבר מופיעים כטיוטות נפרדות בתוך V1. הם אינם עדיין דרישות מאושרות.
