# בדיקת גרפיקה והשוואה חזותית

**מצב: נוספה לדרישות הקבלה לבקשת אדם בתאריך 22/10/2026.**

## המטרה והמקורות

לבדוק את איכות ההצגה בפועל מול משחקים דומים, כחלק ממטרה 2 במסמך [מטרות הפרויקט](../project-goals.md). הבדיקה מתבססת על [מחקר Escape Tsunami](../../research/escape-tsunami-for-brainrots.md) ועל [מפת ההשוואה לשלושה משחקים](../../research/visual-benchmark.md).

## כלל 1: משווים gameplay אמיתי

אוספים צילומים שלנו בבסיס, באיסוף, בחזרה עם מטען מלא ובאזהרת סגירה. כל מצב נבדק במחשב ובנייד מדומה, לפי גדלי המסך בתוך [קריטריוני הקבלה](acceptance.md).

משווים לצילומים מתוך המשחקים שנחקרו, עם מקור, תאריך פרסום כשידוע ומגבלת גרסה. אין להסתמך רק על תמונת פתיחה, thumbnail או זיכרון. צילומים היסטוריים מסומנים ככאלה.

## כלל 2: מה חייב לעבור

| תחום | דרישת קבלה |
| --- | --- |
| סגנון וסביבה | המחסן, הבסיס והחפצים נראים כחלק מאותו משחק; אין אובייקטים חופפים, מרחפים ללא כוונה או פרטים שמפריעים למסלול |
| מסלול ואזורים | מזהים כניסה, בסיס, הפקדה והבדלי ערך; צבע אינו הסימן היחיד |
| חפצים ומטען | חפץ זמין נבדל מהרקע; המטען נראה בלי להסתיר את השחקן או את דרך החזרה |
| UI ותוויות | הטקסט קריא, אין חיתוך או חפיפה, וה־HUD אינו מכסה פעולה חשובה או touch controls |
| מצלמה | הפתיחה מכוונת למחסן; אפשר לראות נתיב ומטרה גם עם מטען מלא ובסמוך לקירות |
| תאורה וצבע | ניגוד מספיק בין פעולה, חפץ ורקע, תוך שמירת התאורה הקבועה שהוגדרה |
| תגובות חזותיות | איסוף, הפקדה, אזהרה וכישלון נבדלים ונראים בזמן משחק, בלי להסתיר את המתרחש |

אנימציה, תנועה ומשך תגובה נבדקים בזמן משחק. צילום סטטי אינו מוכיח אותם. מתחילים בתמונות; משתמשים בקטע קצר וממוקד רק אם צריך לתעד התנהגות שלא נראית בתמונה.

## כלל 3: תוצאה וראיות

לכל תחום רושמים רפרנס מסוים, צילום שלנו, פער, תוצאה ותיקון שנדרש. המצבים: עבר, לא עבר, טרם אומת. כל תחום בטבלה חייב לעבור כדי לסמן את הבדיקה החזותית כמושלמת.

בדיקה אינה עוברת כאשר פרט חיוני מוסתר, הטקסט נחתך, דרך החזרה אינה ברורה או ההצגה סותרת את הסגנון המאושר. לאחר תיקון נדרשת ראיה חדשה מאותה סצנה.

הרפרנסים מגדירים שאלות ואיכות להצגה, ולא דרישה להעתיק assets, מפות או מכניקות. הבדיקה אינה מרחיבה את ההיקף שמופיע בתוך [מפת ההגדרות](../index.md).
