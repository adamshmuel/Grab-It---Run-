# תוכנית מימוש: שמירה

**הרשאה: אדם אישר את הגדרות V1 וביקש להתחיל לבנות בתאריך 22/10/2026.**

מסמך המקור: [הגדרות התחום](../../specs/v1/saving.md).

## סדר העבודה

tests עם storage מוזרק: כישלון טעינה, בעלות על session, שמירה חוזרת, אישור ישן וטעינה מחדש. UpdateAsync עם נעילת session, תור כתיבה והגבלת זמן. בדיקות מקומיות משתמשות ב־storage בזיכרון שמסומן ככזה; אין הפעלת API Services או פרסום ללא אישור.

בכל התנהגות: test נכשל → שינוי מינימלי שעובר → cleanup ו־code review. תוצאות נרשמות בדוח המימוש; לא מסמנים את הגרסה כמתקבלת על בסיס כתיבת קוד בלבד.
