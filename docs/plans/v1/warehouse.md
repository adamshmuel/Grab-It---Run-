## שיפור חזותי שאושר — 23/10/2026

מקור: [הכיוון החזותי](../../specs/v1/visual-direction.md). אדם אישר וביקש להמשיך במימוש.

1. tests נכשלים להבחנה בין שלוש משפחות, מעטפות גודל ושכפול בלי שינוי תבנית המקור. שמירת שלושה דגמי המקור ומיפוי שלהם דרך Rojo בתוך ServerStorage.
2. מודול חזותי משותף משכפל דגם בתרגום, סיבוב וקנה מידה. המחסן והמטען הנישא משתמשים באותו מקור. נקודת האיסוף נשארת קבועה.
3. tests נכשלים להסתרת כל חלקי חפץ אישי, להשארת חפצים אחרים גלויים ולשחזור בסיבוב הבא. תיקון Client בלי שינוי סמכות השרת.
4. tests נכשלים למטען מעורב, ריתוך וללא התנגשות. החלפת קוביות המטען בדגמים הנכונים בלי הסתרת הדמות.
5. tests ממוקדים לפסי אזור, מסגרת כניסה, קירות ומדפים; הוספת צבע ופרטים בלי שינוי מעבר וגבולות המשחק.
6. הפעלה במופע העבודה היחיד; בדיקת איסוף והסתרה, מטען מלא, מצלמה ותצוגת מחשב ונייד. צילומים אמיתיים והשוואה חוזרת לרפרנסים. אין הרצת multiplayer או שאר קבלת הגרסה לפני מעבר הבדיקה החזותית.

בכל שינוי קוד: red → green → cleanup וביקורת בשיחה הראשית. אין קובץ סביבה חדש, אין התקנה ואין פרסום. לאחר סיום בדיקה מוחקים תוצרים זמניים שאינם נחוצים.

## השלמת קריאות המטען בנייד — 24/10/2026

לפי הוראת אדם להמשיך עד השלמת הבדיקות, מתקנים את הפער שנראה בצילומי הנייד: test נכשל לחפץ נישא קטן מדי ולחפיפת דגמים. מגדילים את הדגמים ומסדרים אותם בשתי עמודות ושלוש שורות לכל היותר, לצד הדמות ומאחוריה. גובה כל שורה נגזר מגובה הדגם הגבוה באותה שורה. מסגרת המראה מקיפה את אותו מתקן גם כשהוא ריק. מוודאים ראש וגוף גלויים, ללא התנגשויות, ללא שינוי כללי משחק. אחרי green מצלמים שוב במחשב ובשני פרופילי נייד במופע היחיד.

בדיקת הקיר חשפה גם מעבר דרך מדפי הרקע. test נכשל דורש משטח מדף מוצק ותומכות מחוץ למעבר המרכזי. מתקנים את מאפייני המדף בלי להזיז חפצים, ומוודאים ray איסוף פנוי ותנועה סביב המדף במשחק.

בדיקת תנועה ממושכת הראתה שהדמות יכולה לעלות אוטומטית על לוחות המדף במקום לעצור. מוסיפים test לנפח חסימה פנימי, שקוף וגבוה בתוך גבולות המדף, לפני המימוש. מוודאים שהנפח אינו חוסם נתיבי איסוף חוקיים ואינו מסתיר את המצלמה. לא מסתפקים במדידת מיקום רגעית בזמן MoveTo פעיל.

נמצא קצה מדף בולט שהעלה את הדמות בכ־0.36 studs בזמן ההיתקלות. בדיקת המרחק מהרצפה נשארה נכשלת. בדיקת החסימה דורשת כעת שוליים קטנים מעבר ללוחות כדי שלא ייווצר שלב טיפוס בקצה.

ב־code review נבדקה בפועל משמעות CanQuery: נפח מוצק הוחזר ב־Raycast גם כשמאפיין CanQuery שלו היה false. הוסרה ההגדרה חסרת ההשפעה. ה־test בודק נפח שקוף ומוצק ואת נתיבי האיסוף בפועל, במקום להסתמך על ערך מאפיין שאינו מבטיח החרגה.
