## סדר העבודה

בדיקה רציפה של שחקן חדש, שני שחקנים מדומים, מקרי סגירה, שמירה וחזרה. StyLua, Selene, Rojo build ו־code review בשיחה הראשית. תיעוד נפרד של tests לוגיים, בדיקות Studio ותוצאות שלא הושגו. קבלה מלאה תמתין גם לבדיקות נייד, 8 שחקנים ו־playtests אנושיים.

בכל התנהגות: test נכשל → שינוי מינימלי שעובר → cleanup ו־code review. תוצאות נרשמות בדוח המימוש; לא מסמנים את הגרסה כמתקבלת על בסיס כתיבת קוד בלבד.
