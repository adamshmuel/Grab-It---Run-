# תוכנית מימוש: קבלה ואינטגרציה

**הרשאה: אדם אישר את הגדרות V1 וביקש להתחיל לבנות בתאריך 22/10/2026.**

מסמך המקור: [הגדרות התחום](../../specs/v1/acceptance.md).

## סדר העבודה

בדיקה רציפה של שחקן חדש, שני שחקנים מדומים, מקרי סגירה, שמירה וחזרה. StyLua, Selene, Rojo build ו־code review בשיחה הראשית. תיעוד נפרד של tests לוגיים, בדיקות Studio ותוצאות שלא הושגו. קבלה מלאה תמתין גם לבדיקות נייד, 8 שחקנים ו־playtests אנושיים.

בכל התנהגות: test נכשל → שינוי מינימלי שעובר → cleanup ו־code review. תוצאות נרשמות בדוח המימוש; לא מסמנים את הגרסה כמתקבלת על בסיס כתיבת קוד בלבד.

## בדיקות קבלה שנוספו לבקשת אדם

בודקים גם התאמה למטרות הפרויקט ולמפת ההגדרות, איכות גרפיקה מול שלושת הרפרנסים, עמידה ברמת המתחרים והעדפת שחקנים. הספים החדשים לבחירה אנושית נשארים הצעה לאישור לפני ניסוי. פירוט הבדיקות במסמכי visual-quality ו־competitive-review המקושרים ממפת V1.

## מצב נוכחי

מימוש V1 והבדיקות העצמאיות מתועדים בתוך [מפת הקבלה](../../research/v1-acceptance-status.md) ובתוך [דוח בדיקות ההמשך](../../research/v1-validation.md). בתאריך 24/10/2026 עברו ההשוואה החזותית העצמאית, אחת־עשרה חבילות tests, שניים ושמונה clients, יעד הביצועים ומסלול touch חדש עד פתיחת Copper. אין קבלה מלאה: שמירת ענן, תצפיות אנושיות ושני מגעים במקביל עדיין פתוחים.

## סדר מעודכן לפי החלטת אדם — 23/10/2026

רף חזותי מבוסס רפרנסים בתכנון → אישור ההגדרה → מימוש ובדיקות ממוקדות שלו → השוואה חזותית חוזרת במחשב ובנייד → רק לאחר מעבר, שאר קבלת V1 ובדיקות עם שחקנים. המראה הקודם לא עבר, ולכן נעצר אז multiplayer. הוראת ההמשך מתאריך 24/10 להלן איפשרה את הבדיקות הנדרשות לאחר מעבר השער החדש; בסופן חזרנו לחלון עבודה אחד.

## המשך עצמאי — הוראת אדם, 24/10/2026

אדם ביקש להשאיר את המחשב ער ולהשלים את כל העבודה האפשרית בלי לבקש ממנו לבדוק גרסה שלא עברה קבלה. השיחה הראשית מבצעת את ההשוואה והתיקונים החזותיים; אין בקשת אישור ביניים על הצילומים. אחרי מעבר השער העצמאי משלימים גם את בדיקות ה־multiplayer והביצועים שהוגדרו, במופעים זמניים רק כאשר נדרשים, ומחזירים לחלון עבודה אחד. אין פרסום, שינוי הרשאות API או פנייה לשחקנים ללא הרשאה. בדיקות אנושיות ושמירה אמיתית נשארות דרישות, גם אם אין אפשרות להשלים אותן בכלים ובהרשאות הנוכחיים.
