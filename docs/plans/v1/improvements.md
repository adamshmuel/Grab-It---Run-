# סדר מימוש מקצה שיפורי V1

אושר מימוש בתאריך 25/10/2026. מקור: [מפת ההגדרות](../../specs/v1/improvements.md).

1. בדיקות היתכנות ממוקדות ותיעוד מגבלות.
2. [קטלוג](item-catalog.md) וכן [נשיאה](carrying-weight.md).
3. [שלבים ודירוג](stage-progression.md).
4. [רכישות](cosmetics.md) וכן [שמירה](saving.md).
5. [סביבה](stage-content.md), דגמים ונשיאה חזותית.
6. [Controls](controls-feedback.md) וחיבור השרת והלקוח.
7. TDD וכן code review לקוד שהשתנה, ניקוי ושמירת התוצאה.
8. **עצירה לפני בדיקות הקבלה**, לפי [גבול הבדיקות](improvement-acceptance.md), כדי שאדם יוכל להעלות את חוזק המודל.

המימוש יישאר ללא פרסום. ההשוואה למתחרים, בדיקת החוויה, מסעות בפועל, multiplayer, נייד ושמירה בענן שייכים לשלב הבא ולא יתבצעו לפני העצירה. בדיקות פיתוח ממוקדות אינן תחליף להם.

## מצב הביצוע

שלבים 1 עד 7 בוצעו בהיקף המתועד בתוך [דוח המימוש](../../research/v1-improvement-implementation.md). נקודת העצירה בשלב 8 כובדה. בתאריך 26/10/2026 אדם חידש את העבודה לאחר העלאת חוזק המודל. בתחילת שלב הבדיקות משלימים תחילה את שער העיצוב מול הרפרנסים, ורק לאחריו פריסה והסתרה מפורטות ויתר הקבלה לפי הכללים המעודכנים. ההתקדמות והפערים בתוך דוח הבדיקה הנוכחי.
