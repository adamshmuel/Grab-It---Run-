# ראיות מקומיות של V1

נאספו בתאריך 23/10/2026 באמצעות Studio MCP בקובץ המשחק המאומת. אלה בדיקות Studio מקומיות, לא בדיקות ענן ולא playtests אנושיים.

קובצי JSON כוללים את תוצאת כלי הבדיקה, תוצאות החבילות ודיווחי clients. המפתח ok מציין שהפעלת כלי הבדיקה הסתיימה; result.passed הוא תוצאת המשחק. אין לפרש ok בלבד כהצלחה. קובצי failure ו־red נשמרים לצורך שחזור התקלה, ולא נחשבים בדיקות שעברו. interim הוא צילום מצב ביניים בלבד.

- sparse-state-red/green: בדיקת שני שחקנים עם רשימת חפצים דלילה, לפני ואחרי תיקון קידוד המצב.
- repeat-and-leave: יציאות חוזרות ויציאת שחקן, עם כלי הבדיקה הקודם. אינו מחליף את בדיקת המצב הדליל.
- session-passed: סיבוב מלא עם שני שחקנים, לפני התיקונים האחרונים.
- images/desktop-cargo-after.png: צילום שלנו ב־1920 על 1080, מטען מלא לאחר הזזתו מהראש. קדם לתיקון מרחק פתיחת המצלמה ולתיקון הרשת; ראיה מוגבלת לתצוגה הזאת.

פרטי ההרצות, הגרסאות והמגבלות נמצאים בתוך [דוח הבדיקות](../../v1-validation.md). מקורות כלי QA נמצאים בתיקיית tools/qa. חומרי המתחרים נשארים בנפרד בתיקיית references המקומית, עם רישום מקורות; הם אינם assets של המשחק.

- native-visual-prototypes.json: ייצוא שלושה דגמי Roblox ובדיקת המבנה שלהם. אינה בדיקה בתוך Studio או אישור לאיכות המראה.
