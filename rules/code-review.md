# Code review

- כל שינוי קוד מחייב code review לפני שמציגים את משימת הקידוד כמושלמת. הכלל חל על קוד חדש, תיקון bug ושינוי בקוד קיים.
- עוברים על השינוי ועל הקוד שמושפע ממנו. בודקים התאמה ל־spec המאושר, נכונות ההתנהגות, מקרי קצה, אבטחה, קריאות וכיסוי באמצעות tests.
- בשינויי Roblox/Luau משתמשים במיומנות `roblox-code-review` לפי הצורך ובהיקף שמתאים לשינוי.
- מתקנים בעיות שנמצאו ובודקים שוב את הקוד שתוקן. מריצים את ה־tests הרלוונטיים בהתאם לכללי TDD ולהרשאות המשימה. Code review אינו מחליף tests או playtests.
- מסכמים בקצרה מה נבדק, אילו בעיות תוקנו ואילו מגבלות בדיקה נשארו. אין להציג בדיקה שלא בוצעה כאילו עברה.
- כברירת מחדל, ה־code review מתבצע בשיחה הראשית. הכלל אינו מחייב אישור בודק נפרד לפני commit ואינו מעניק הרשאה להפעיל subagent.
- שינויי תיעוד בלבד אינם מחייבים code review. יש לקרוא אותם ולבדוק שהם ברורים ועקביים עם כללי הפרויקט.
